Public Data · Motion · Sound

Data Art Galleries

Each room takes one public data set that was easy to find and hard to use, and turns it into motion and sound. An agent built each room, from the data pull to the sound design, and the first thirteen were built in parallel in one afternoon. Every room has its own visual language, from a radar scope to a nautical chart to a hydraulic machine.

How to visit

Open a room, then click once to Enter with sound. The chip at the bottom left of every room moves to the next room and mutes the sound. Each room links to a README with the source, the sampling rule, and the sound mapping. Source code lives on GitHub.
